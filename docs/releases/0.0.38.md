# ZIPP 0.0.38

A compatibility and performance release resolving Node ESM module resolution and exit-code handling, expanding Python standard library parity for real-world HTML extraction and CI policy workloads, fixing `zipfile` deflate compression, text-mode universal newlines, `initPythonProject` entry paths, and quadratic Python regex astral-offset conversion, and accelerating DOM/HTML parsing throughput in the JavaScript JIT and runtime.

Thank you to [@codeandsolder](https://github.com/codeandsolder) for reporting issues #99 through #107 with clear minimal reproductions, exact expected behavior, and real-world HTML and Python benchmarks — your reports made every one of these fixes and speedups straightforward to pinpoint and verify.

## New in 0.0.38

- **Node ESM `import.meta.resolve` and `process.exitCode` (#99):**
  - Implements `import.meta.resolve(specifier, parent?)` using the same ESM resolution algorithm as actual `import` statements (`node:` builtins, `package.json` `exports`/`imports`, scoped/subpath packages, and relative/file URLs).
  - Propagates `process.exitCode` through normal script, module, and TypeScript completion (with numeric/string coercion and `0` default).
- **DOM/HTML parsing & JS JIT throughput (#101):**
  - Unlocks native JIT cross-calls and ES module leaf inlining when `global_route_epoch != 0` (as after Node's lazy `globalThis` bootstrap), unboxes uncaptured destructured locals in arrow functions, enables `Float32Array` on the XMM `DOUBLE` register-allocated loop tier with NaN canonicalization, and folds hoisted pinned-receiver nullish checks (`bias === void 0 ? 0 : bias[row]`).
  - Adds a direct-mapped `class_member_cache` with GC/prototype epoch invalidation, fast `Walked::ClassGetter` routing, `%RegExp.prototype%` fast-slot caching plus a pristine non-global `str.match(re)` path, and pooled allocation reuse (`upval_pool`, `byte_pool`, `arr_pool`, interned ASCII) across closures, regex slices, arrays, and string operations.
  - On the #101 steady-state HTML parsing reproduction (fat-LTO vs. fat-LTO, exact outputs): WebforAI repeat median drops from `216.6 ms` to `123.3 ms` (1.76× faster, first call `251.9 ms` → `183.0 ms`) and Defuddle repeat median drops from `232.0 ms` to `174.8 ms` (1.33× faster, first call `309.0 ms` → `241.9 ms`).
- **Python standard library parity for real-world packages & CI oracles (#100, #103):**
  - Adds 23 original Apache-2.0 stdlib modules: `_markupbase`, `html`, `html.entities`, `html.parser`, `urllib`, `urllib.parse`, `urllib.error`, `urllib.response`, `urllib.request`, `warnings`, `codecs`, `logging`, `copyreg`, `threading`, `binascii`, `base64`, `tempfile`, `datetime`, `shlex`, `tomllib`, `importlib.util`, `unittest`, and `unittest.mock`.
  - Runs unmodified `html2text`, `markdownify` (`beautifulsoup4`, `soupsieve`, `typing_extensions`), and pure-Python `PyYAML` with output matching CPython byte-for-byte.
- **Python `pathlib`/`read_text` and compiled `re.findall` throughput (#102):**
  - Adds a native `py_re_findall` fast path (safe-sandbox compatible) and streamlines `pathlib.Path.glob`/`rglob`/`read_text` traversal; cuts the 353-file / 31,770-match Markdown scan from `0.304 s` to `0.084 s`.
- **Python `zipfile` `ZIP_DEFLATED`, `compresslevel`, `zlib`, and `shutil` (#104):**
  - Implements zero-dependency RFC 1950/1951 deflate/inflate across compression levels 0–9, wires `zlib` and `shutil`, and adds `ZIP_DEFLATED` and `compresslevel` support to `zipfile`.
- **Python text-mode universal newline translation (#105):**
  - Translates `\r\n` and `\r` according to `newline=None`, `""`, `"\n"`, `"\r"`, and `"\r\n"` on text-mode reads and writes in `open()` and `pathlib.Path`.
- **`initPythonProject` with non-identifier entry directories (#106):**
  - Fixes `zipp-wasm` Python project execution when the entry script lives beneath a directory segment that is not a valid Python identifier (for example `fixtures/with-hyphen/verify.py`).
- **Python `re` linear astral-offset conversion (#107):**
  - Replaces quadratic per-match UTF-16↔code-point scanning with an O(N) prefix table and O(log N) lookup so regex workloads with astral characters scale linearly.
