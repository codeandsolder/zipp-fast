# ZIPP 0.0.37

A major polyglot and performance release adding PHP 8.x and Rust language frontends and WebAssembly modules (`javascript-php` and `javascript-rust`), Python 3.13 syntax and stdlib parity with new JIT fast paths, composable sandboxed plugin bridges, JS VM and Tier-C/Tier-O JIT optimizations, and an updated Test262 pin.

## New in 0.0.37

- **PHP 8.x frontend, HTTP SAPI/Worker Mode, and WebAssembly module (`zipp-0.0.37-javascript-php.wasm`):**
  - Full PHP 8.x parser, compiler, and runtime with PSR-4 autoloading, OOP/traits/enums/magic methods/reflection, Slim/Laravel/CakePHP framework semantics, selective x86-64 JIT acceleration, and disk OPcache.
  - `PhpApp` SAPI & Worker Mode in `zipp-wasm`, with `PDO` and `mysqli` bridged over host-owned `app.sql.*` capabilities (for example XDB SQLite in browser sandboxes).
- **Rust frontend, Axum/SQLx backend support, and WebAssembly module (`zipp-0.0.37-javascript-rust.wasm`):**
  - Rust parser, frontend, runtime, CLI (`zipp rs`, `--serve`, `--watch`), and browser WebAssembly module.
  - Supports Axum 0.7 routing/extractors/middleware/WebSockets, SQLx over `app.sql.*`, `serde`, `argon2`, `jsonwebtoken`, `uuid`, `time`, `tokio::try_join!`/`select!`, and raw binary VFS overlay persistence (`File::write_all` / `append_bytes_hex`).
- **Python 3.13 parity & JIT acceleration:**
  - Adds `async`/`await`, `except*`, PEP 695 type parameters, and `asyncio`, `fractions`, and `numbers` stdlib modules.
  - Adds frame-less acyclic leaf calls (`py_leaf`), self-recursive x86-64 micro-JIT (`py_rec`), inline list/tuple/math JIT paths, and fast generator stepping.
- **Sandboxed plugin bridges & shared metering:**
  - Composable `addAppBridge(namespace, bridge)` in `zipp-wasm`, unified `HostCtx::steps_remaining`/`charge_steps`, and `hostStepsRemaining`/`hostChargeSteps` exports so external sandboxed plugins (such as XDB SQLite) share the guest VM's instruction budget without expanding the audited 51-function WASM import surface.
- **JavaScript VM, parser & JIT speedups:**
  - Skip-body preparser, megamorphic property/index/call memos, 24/32-slot value slabs, minor-GC ephemeron/root delta paths, Tier-O `TaggedTruthy` `SmallBigInt` fix, and Test262 corpus updated to `2e58f87d83` with three newly covered spec edges fixed.
